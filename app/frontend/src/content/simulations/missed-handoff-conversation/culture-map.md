# The Culture Map (Adapted)

Adapted from Erin Meyer's *The Culture Map*.

| Dimension | Sliding scale |
| --- | --- |
| Communicating | More implicit ←→ More explicit |
| Evaluating | More indirect feedback ←→ More directed feedback |
| Persuading | Reasoning first ←→ State the recommendation first |
| Leading | Rank matters less ←→ Rank matters more |
| Deciding | More group consensus ←→ More top-down |
| Trusting | More task-based ←→ More relationship-based |
| Disagreeing | More indirect disagreement ←→ More direct disagreement |
| Scheduling | More fixed ←→ More flexible |

## How to use it

The eight dimensions provide possibilities for more nuanced communication.

Each dimension is a sliding scale. Neither end is automatically better. What works can change depending on the person, the relationship, the situation and the context.

A placement is a hypothesis about one person, not a rule about a country. Use nationality, role, age, background and organisation to form the guess, then watch the conversation for evidence that confirms or corrects it.
