# Crimson Cup glossary

- **Kopi**: coffee with condensed milk and standard sugar.
- **O**: no milk.
- **C**: evaporated milk instead of condensed milk.
- **Kosong**: no sugar.
- **Siew dai**: less sugar.
- **Peng**: iced.
- An item must be ordered by an available menu code. Do not construct an off-menu code.
- “Something less sweet” is ambiguous because the order does not specify a base drink or milk preference. Ask Dev to clarify.
- Elena's exact requested combination is unavailable. Offer an available no-dairy alternative and confirm it before finalizing.
